# Meu TCC 2 — área de transição

Esta pasta mantém duas cópias de referência para migrar o trabalho com segurança.

- `template-professor/`: template atualizado de TCC 2. Este é o ponto de partida para a versão final.
- `meu-tcc-original/`: cópia preservada do TCC já desenvolvido. Não a edite durante a migração; use-a para copiar e adaptar o conteúdo.

## Fluxo de trabalho

1. Copie e adapte uma seção por vez do `meu-tcc-original/` para `template-professor/tcc2.tex`.
2. Leve as referências necessárias para `template-professor/bibliografia_tcc2.bib`.
3. Coloque as figuras usadas em `template-professor/assets/` e atualize os caminhos no documento.
4. Compile o novo documento e revise antes de seguir para a próxima seção.

O trabalho ativo ficará em `template-professor/`; a cópia original continuará disponível para consulta.
